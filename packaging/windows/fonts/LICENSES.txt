Bundled fonts
=============
These 150 font files ship with Forge Design. They come from the Debian/Ubuntu
font packages of the same name (fonts-roboto, fonts-open-sans, fonts-lato,
fonts-inter, fonts-montserrat, fonts-ibm-plex, fonts-noto-core, fonts-texgyre,
fonts-dejavu, fonts-liberation2, ...). All are free to use and redistribute
under their own licenses — mainly the SIL Open Font License 1.1 and the
Apache License 2.0, plus the GUST Font License (TeX Gyre), the Bitstream Vera
license (DejaVu) and GPL-with-font-exception (Linux Libertine / Biolinum).
Upstream copyright notices are embedded in each font file.
